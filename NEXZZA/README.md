# NEXZZA

A gaming community using Next.js App Router, strict TypeScript, Tailwind, Supabase Auth, Postgres RLS, Realtime and private Storage. This checkout continues the original NEXZZA Site; it does not replace its database or Site identity.

- Email/password accounts, verification and recovery
- Global lobby, invite-only direct and group chats, replies, reactions, edits, soft deletion, receipts, typing and activity
- Validated uploads and recorded voice notes
- Player-created news, local Today/Archive, server-ranked Trending, likes, threaded comments, private bookmarks, sources and sharing
- Profiles, privacy controls, blocks and notifications
- Role-protected moderation, reported-content snapshots, audit log and community settings

See [operations](docs/OPERATIONS.md) for email configuration, first administrator setup, retention and deployment. See [QA](docs/QA.md) for test coverage and limitations.

No production example users, fabricated news, or test credentials are shipped.
